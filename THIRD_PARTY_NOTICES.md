# Android source provenance and notices

Aro’s UI is inspired by PixelPlay. Aro also contains source adapted from upstream projects; the relationship is not limited to visual inspiration. Renaming an app or replacing artwork does not change the origin or license of that source.

- **PixelPlay**, Theo Vilardo and contributors: https://github.com/theovilardo/PixelPlay. Original UI and application code form the upstream base. The original root `LICENSE` and copyright notice are preserved verbatim.
- **Meld**, Francesco Grazioso and contributors: https://github.com/FrancescoGrazioso/Meld. Music discovery, queue behavior, and Spotify integration include adaptations from Meld, including the local Meld source supplied during development. Its GPLv3 obligations and original source notices remain applicable.
- **InnerTubeX**, Metrolist contributors: https://github.com/MetrolistGroup/innertubex. Adapted YouTube Music protocol and playback sources and the original GPLv3 license are included in `innertubex/`.

The combined app’s distribution rights remain unresolved; see [LICENSE_STATUS.md](LICENSE_STATUS.md). This provenance record does not grant new rights or replace upstream license texts. Website dependencies have separate [notices](web/THIRD_PARTY_NOTICES.md).
